# NEXUS AI — تشغيل نموذج محلي داخل المتصفح

واجهة عربية لمحادثة نموذج مفتوح الأوزان مباشرة في المتصفح، باستخدام Transformers.js ونموذج `onnx-community/Qwen2.5-0.5B-Instruct`.

## التشغيل
1. ارفع الملفات `index.html` و`style.css` و`script.js` إلى مستودع GitHub.
2. من إعدادات المستودع افتح **Pages**، ثم اختر النشر من الفرع الرئيسي (`main`) ومجلد الجذر (`/root`).
3. افتح رابط GitHub Pages، واضغط **تحميل النموذج**.
4. أول تشغيل يتطلب اتصالًا بالإنترنت لتنزيل مكتبة التشغيل وملفات النموذج. قد تكون الملفات كبيرة، وتُخزَّن مؤقتًا في المتصفح حسب دعم الجهاز.
5. بعد تنزيل النموذج، تتم عملية التوليد على جهاز المستخدم. لا يستخدم المشروع مفتاح API أو خادم محادثات.

## ملاحظات مهمة
- النموذج صغير نسبيًا (0.5B) لتجربة التشغيل المحلي؛ جودته وقدرته أقل من النماذج السحابية الكبيرة.
- الأداء يعتمد على الهاتف والمتصفح والذاكرة ودعم WebGPU. الكود يحاول WebGPU أولًا ثم WASM.
- بعض المتصفحات قد لا تدعم WebGPU أو قد تفشل بسبب قيود الذاكرة.
- النموذج مدرّب مسبقًا، لذلك ليس فارغًا ولا يتعلم تلقائيًا من محادثاتك. سجل المحادثة يبقى في ذاكرة الصفحة فقط ولا يُستخدم لتحديث أوزان النموذج.
- قد يرفض النموذج بعض الطلبات بسبب تدريبه الأصلي؛ هذا المشروع لا يضيف طبقة رفض خاصة به ولا يمكنه ضمان استجابة النموذج لكل طلب.
- افحص ترخيص النموذج وشروط توزيعه قبل استخدامه تجاريًا.
- الواجهة تستخدم خطوط النظام فقط، ولا تستدعي Google Fonts.
